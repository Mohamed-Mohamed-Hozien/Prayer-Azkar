# 🕌 تطبيق صلاتي وأذكاري (Prayer Times & Athkar)

تطبيق إسلامي شامل ومفتوح المصدر يعمل بدون إنترنت بنسبة 100%، مبني باستخدام React 19 + Capacitor 8 للأندرويد.

## ✨ المميزات الرئيسية:
- **مواقيت الصلاة الفلكية الدقيقة**: تدعم 12 طريقة حساب عالمية، ومذهبي العصر (شافعي/حنفي)، وتعديل التاريخ الهجري.
- **بوصلة القبلة التفاعلية**: تعتمد على حساسات الجيروسكوب والمغناطيسية مع اهتزاز وإضاءة عند الاتصال المباشر بالكعبة (±3°).
- **السبحة الإلكترونية الذكية**: عداد لمسي دائري تفاعلي مع اهتزاز، أهداف تسبيح (33، 99، 100، 1000، حر)، واحتفال عند إتمام الهدف.
- **حصن المسلم والأذكار**: أذكار الصباح والمساء، أذكار بعد الصلاة، أذكار النوم، الرقية الشرعية، وإضافة أذكار مخصصة.
- **أصوات الأذان والمؤذنين**: مكتبة صوتية لمؤذني الحرم المكي، المسجد النبوي، الأقصى، الشيخ العفاسي، عبد الباسط، الحصري، والقطامي، بالإضافة لإمكانية رفع أذان مخصص (MP3).
- **تنبيه صوتي مسبق للإقامة**: نداء صوتي باللغة العربية قبل الإقامة بخمس دقائق.
- **ودجت الشاشة الرئيسية وشاشة القفل**: إشعار دائم مثبت لا يمكن حذفه بالخطأ مع ودجت أندرويد متزامن في الوقت الفعلي.
- **5 سمات ومظاهر فاخرة**: الزمردي والذهبي، الأسود الليلي الداكن OLED، الأزرق الملكي، رمل الصحراء والغروب، والنهاري المشرق.
