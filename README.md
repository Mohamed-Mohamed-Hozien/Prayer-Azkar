تطبيق إسلامي شامل، خفيف، بدون إعلانات، ومفتوح المصدر (Open Source) يعمل بدون إنترنت بنسبة 100%، مبني باستخدام **React 19 + Vite 6 + Capacitor 8 + Android Native** ومتجاوب بالكامل مع جميع الهواتف والأجهزة اللوحية (Tablets).

---

## ✨ المميزات الرئيسية (Core Features)

- **🕌 مواقيت الصلاة الفلكية الدقيقة**: تدعم 12 طريقة حساب عالمية (الهيئة المصرية، أم القرى، رابطة العالم الإسلامي، ISNA، دبي، الكويت، قطر، كراتشي، سنغافورة، فرنسا، تركيا، ورؤية الهلال)، ومذهبي العصر (شافعي/حنفي)، والتقويم الهجري والميلادي معاً.
- **🧭 بوصلة القبلة التفاعلية 3D**: تعتمد على حساسات التوجيه الجغرافي (`DeviceOrientation`) مع اهتزاز تفاعلي وإضاءة ذهبية عند الاتجاه المباشر للكعبة المشرفة (±3°).
- **📿 السبحة الإلكترونية الذكية**: عداد لمسي دائري تفاعلي مع اهتزاز، أهداف تسبيح (33، 99، 100، 1000، حر)، تصفير يومي تلقائي عند منتصف الليل، و10 أذكار مأثورة مع فضائلها.
- **📖 حصن المسلم والأذكار**: أذكار الصباح، أذكار المساء، أذكار بعد الصلاة، أذكار النوم، التسبيح، وإمكانية إضافة أذكار وأدعية مخصصة.
- **🔊 مكتبة الأذان المدمجة (أوفلاين)**: أصوات مؤذني الحرم المكي، المسجد النبوي، الأقصى، الشيخ العفاسي، وعبد الباسط عبد الصمد، مع إمكانية رفع أذان مخصص (MP3/WAV).
- **🔔 تنبيه صوتي ورنة للإقامة**: رنة تنبيه هادئة صاعدة قبل الإقامة بخمس دقائق وتنبيه عند موعد الإقامة.
- **📱 ودجت الشاشة الرئيسية وشاشة القفل**: ودجت أندرويد أصلي (Native AppWidget 4x2) متزامن في الوقت الفعلي مع إشعار دائم مثبت.
- **🎨 5 سمات ومظاهر فاخرة**: الزمردي والذهبي، الأسود الليلي الداكن OLED، الأزرق الملكي، رمل الصحراء والغروب، والنهاري المشرق.
- **💻 تصميم متكيف وداينامك (Adaptive Responsive Layout)**: يعمل بكفاءة عالية على الهواتف الصغيرة، الكبيرة، الهواتف القابلة للطي، وأجهزة التابلت 7 إلى 12 بوصة.

## 🚀 البدء السريع للمطورين (Quick Start)

```bash
# استنساخ المستودع
git clone https://github.com/Mohamed-Mohamed-Hozien/Prayer-Azkar.git
cd Prayer-Azkar

# تثبيت الحزم
npm install

# تشغيل خادم التطوير المحلي
npm run dev

# بناء حزمة الإنتاج
npm run build

# مزامنة الكود مع مشروع الأندرويد الأصلي
npx cap sync android
```
