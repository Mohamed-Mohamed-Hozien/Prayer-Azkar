⚙️ المعمارية التقنية وكفاءة الأداء (Architecture & Performance) ⚙️ Technical Architecture & Performance

معمارية خفيفة بدون أي حمل زائد Clean Offline Architecture & Zero-Overhead

Frontend Layer: React 19 + Vite 6 مع Vanilla CSS Tokens بدون مكتبات ثقيلة، لضمان استجابة 60fps. React 19 + Vite 6 with pure CSS tokens—zero Tailwind/heavy CSS bloat.
Offline Storage Hierarchy: طبقتان محليتان: LocalStorage للإعدادات الفورية، و IndexedDB للأصوات والبيانات الكبيرة. Two-tier local storage: LocalStorage for instant keys, IndexedDB for audio blobs.
Native Android Bridge: Capacitor 8 مع Android Java Native Widgets و Local Notifications للتشغيل في الخلفية. Capacitor 8 with native Java home-screen widgets and background notifications.
Network Isolation: صفر طلبات شبكة يومياً، مما يحافظ على عمر البطارية بنسبة تصل إلى 4 أضعاف. Exactly zero network calls per day, prolonging battery life up to 4x.
