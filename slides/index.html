معمارية خفيفة بدون أي حمل زائد Clean Offline Architecture & Zero-Overhead

Frontend & Routing: React 19 + Hash Router مع دعم زر الرجوع للهاتف (Hardware Back Button) وتقسيم الكود (Code Splitting). React 19 + Hash Router with hardware back-button handling & code splitting.
